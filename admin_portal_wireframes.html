Admin Portal — User Stories
Complete user stories for Enrollment Management, Batch Creation, Course Assignments, and Job Specifications.
Enrollment Management
US-ADM-ENR-001
Enrollment
As an LMS Administrator
I want to enroll a single employee in a specific course by searching for them by name, employee ID, or department, so that I can quickly onboard a new hire or assign remedial training without needing to create a batch.
Acceptance Criteria
✓ I can search employees by name, employee ID, email, or department
✓ I can select one or more courses from the course catalogue
✓ I can set a custom due date (overrides course default)
✓ System prevents duplicate enrollment (same user + course + active)
✓ Employee receives in-app notification + email upon enrollment
✓ Enrollment is logged in audit trail with my admin ID (21 CFR 11)
US-ADM-ENR-002
Enrollment
As an LMS Administrator
I want to view a filterable, paginated list of all enrollments with status indicators (enrolled, in-progress, completed, overdue, failed), so I can monitor compliance status across the organisation at a glance.
Acceptance Criteria
✓ Table shows: employee name, course, department, status, due date, progress %, enrolled date
✓ OVERDUE status is always shown in red (#DC2626)
✓ Filter by: status, department, course, due date range, assigned by
✓ Export filtered results to CSV (audit-logged)
✓ Clicking a row opens enrollment detail panel
US-ADM-ENR-003
Enrollment
As an LMS Administrator
I want to bulk enroll employees using a CSV upload, specifying employee IDs and course codes, so I can enroll an entire department or cohort without doing it one-by-one.
Acceptance Criteria
✓ I can download a CSV template with required columns
✓ System validates the file before committing: shows row-by-row errors (invalid IDs, missing fields)
✓ I can review the validation summary before confirming
✓ Partial import is allowed (skip errored rows, enroll valid ones)
✓ System sends enrollment notifications only after commit
✓ Import job result (rows enrolled, rows skipped) shown and exportable
US-ADM-ENR-004
Enrollment
As an LMS Administrator
I want to modify or cancel an existing enrollment (change due date, reassign to a different course version, or cancel), so I can handle course updates, employee transfers, and training plan corrections.
Acceptance Criteria
✓ Due date change requires a documented reason (GxP reason field)
✓ Cancellation of a completed enrollment is not allowed without manager approval
✓ All modifications create an immutable audit trail entry
✓ Employee notified of any change to their enrollment
Batch Management
US-ADM-BAT-001
Batch
As an LMS Administrator
I want to create a named training batch (a group of employees + a set of courses + a shared timeline), so I can coordinate training for an entire department cohort or a regulatory training cycle in one operation.
Acceptance Criteria
✓ Batch has: name, description, start date, end date, department(s), course list
✓ I can add members by: individual search, department selection, or job specification
✓ Batch auto-calculates per-course due dates from start date + course duration
✓ Batch can be saved as DRAFT before committing enrollments
✓ Activating a batch creates all enrollment_records in a single transaction
✓ Batch status: Draft → Active → Completed → Archived
US-ADM-BAT-002
Batch
As an LMS Administrator
I want to view a batch roster with per-member progress, so I can monitor overall batch completion rate, identify who is falling behind, and send targeted reminders.
Acceptance Criteria
✓ Roster shows each member's completion % per course
✓ Overall batch completion gauge shown at top
✓ I can send a reminder notification to all overdue members in one click
✓ I can add or remove members from an active batch (with audit trail)
✓ Batch report is exportable for QA review
US-ADM-BAT-003
Batch
As an LMS Administrator
I want to clone an existing batch to create a new training cycle (e.g., annual retraining), so I don't have to reconfigure courses and department membership from scratch.
Acceptance Criteria
✓ Clone copies: name (appended with year/cycle), courses, department filters — not members
✓ Cloned batch starts in DRAFT; I set new dates before activating
✓ Members are re-resolved at activation (picks up staff changes since last cycle)
Course Assignment
US-ADM-ASN-001
Assignment
As an LMS Administrator
I want to assign a course to an entire department in one action, setting a shared due date, so I can meet compliance deadlines for regulatory training (e.g., GMP refresher) across all relevant staff.
Acceptance Criteria
✓ I select a course, select one or more departments, set a due date
✓ System shows a preview count: "This will enroll 47 employees"
✓ Employees already enrolled in that course version are excluded automatically
✓ Assignment is tagged with compliance_required = true if marked as such
US-ADM-ASN-002
Assignment
As an LMS Administrator
I want to assign courses by job specification, so that when a new employee is hired or transferred, all courses required for their role are automatically enrolled in one click using the job spec's training matrix.
Acceptance Criteria
✓ I select the job specification and the employee; system resolves the required + optional courses
✓ Required courses are marked compliance_required = true
✓ Due dates are calculated from hire date + each course's offset_days
✓ I can deselect optional courses before confirming
Job Specifications
US-ADM-JOB-001
Job Spec
As an LMS Administrator
I want to create and manage job specifications (job role profiles) that define the mandatory and optional training courses required for each role, so that onboarding and annual retraining can be driven systematically from the training matrix.
Acceptance Criteria
✓ Job spec has: title, department, grade/level, regulatory category, description
✓ I can add courses to the spec as Required (mandatory) or Recommended (optional)
✓ Each course entry has a due_offset_days (days from hire/transfer date)
✓ Job spec has a version number; editing creates a new version (previous immutable)
✓ A job spec can be linked to one or more job titles in the HR system
US-ADM-JOB-002
Job Spec
As an LMS Administrator
I want to view the training matrix (a grid of job roles vs courses showing required/optional/not-applicable status), so I can quickly audit our training coverage and identify gaps for regulatory inspections.
Acceptance Criteria
✓ Matrix shows all active job specs as rows, all active courses as columns
✓ Each cell shows: R (required), O (optional), — (not applicable)
✓ I can filter by department or regulatory category
✓ Matrix is exportable as Excel for regulatory submission
✓ Clicking a cell opens an inline editor to change requirement status
US-ADM-JOB-003
Job Spec
As an LMS Administrator
I want to see which employees are assigned to each job specification and their overall training compliance against that spec, so I can generate a per-role compliance report for QA audits.
Acceptance Criteria
✓ Job spec detail page lists all assigned employees with: compliance %, overdue courses, certificates status
✓ Summary shows: fully compliant count, partially compliant count, non-compliant count
✓ Report can be generated as PDF/CSV for QA submission
