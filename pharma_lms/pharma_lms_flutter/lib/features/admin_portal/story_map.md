# Admin Story to Screen Map

## Compliance Scoring and Forecasting
- `analytics/dashboard`: compliance KPI, risk forecast, engagement indicators
- `reports/compliance`: organization-level compliance overview

## Audit Integrity and E-signature Verification
- `audit/trail`: immutable event search
- `audit/integrity`: chain verification and tamper check entry point
- `reports/regulatory`: inspection package generation entry point

## Notification Templates and Reminder Rules
- `notifications/templates`: event templates and channel selection
- `notifications/rules`: reminder cadence, escalation, targeting
- `notifications/broadcast`: ad-hoc notices for departments/sites

## Data Portability, Erasure, Retention
- `system/gdpr`: DSAR portability and erasure workflow controls
- `system/retention`: retention windows and archival policy controls

## System and Integration Governance
- `system/settings`: org branding/timezone and defaults
- `system/hr-integration`: master-data sync configuration
- `system/api-keys`: key issuance and rotation
- `system/health`: operational telemetry and alerting
- `system/validation-docs`: CSV/GAMP document registry
